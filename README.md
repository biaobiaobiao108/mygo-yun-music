# 云鹿音乐 for MyGo Music

把自建的[云鹿音乐](https://github.com/biaobiaobiao108/yun-music)服务器接入 MyGo Music。插件通过云鹿音乐的 HTTP API 读取搜索、专辑、艺人、歌单、排行榜、歌词、评论和播放历史，并把播放地址交给 MyGo 的播放器。

## 要求

- MyGo Music 0.1.8 或更高版本。
- 一台可访问的云鹿音乐服务器。
- 播放歌曲需要服务器已为你的账号启用支持对应平台（`wy` 或 `tx`）的自定义音源脚本。云鹿音乐的内置 SDK 能提供搜索和元数据，但实际播放地址来自自定义音源。

## 安装

在 MyGo Music 中打开“设置 → 插件”，点“+”，选择“从文件夹安装”，选中本目录即可。也可以把本目录压缩成 zip 后安装，或放到 MyGo 的插件目录中。

插件 ID 为 `yun-music`，显示名为“云鹿音乐”。

## 设置

| 设置 | 说明 |
| --- | --- |
| 服务器地址 | 云鹿音乐的根地址，例如 `http://192.168.1.10:9527`。浏览器地址里的 `/music` 和 `#/...` 会自动忽略。 |
| 音源 | 可填 `wy`（网易云音乐）或 `tx`（QQ 音乐）覆盖；留空时跟随云鹿音乐播放器的默认音源。 |
| 用户名 / 密码 | 云鹿音乐的播放器账号。收藏、歌单和播放历史需要登录；只浏览和搜索可以不填。 |
| 播放器密码 | 仅当服务器启用了播放器密码时填写。 |

服务器地址可以带 `http://` 或 `https://`；不写协议时按 `http://` 处理。不要把用户名或密码写进地址。

## 功能

- 搜索歌曲、专辑、艺人和歌单，支持分页。
- 首页展示最近播放、我的歌单、排行榜和发现。
- 排行榜显示榜单封面；账户菜单和缺失封面使用随插件打包的云鹿音乐图标。
- 专辑、艺人、在线歌单和排行榜详情。
- 歌词（原文与翻译）。
- 评论列表。
- 播放，按 MyGo 的音质设置请求 `flac`、`320k` 或 `128k`；是否自动切换音源、自动降级音质由云鹿音乐播放器设置决定。
- 播放优先复用云鹿音乐已有的服务端下载/缓存；在线播放开始后按云鹿音乐的 `enableServerCache`、歌词缓存和嵌入歌词设置提交后台缓存任务。
- 收藏歌曲、保存专辑、关注艺人。
- 创建、重命名、删除歌单，添加、移除和移动歌曲。
- 保存或取消保存在线歌单与排行榜。
- 最近播放同步。

## 限制

- MyGo 的流式播放器支持 `mp3`、`flac` 和 `ogg`。服务器返回 `m4a`、`aac`、`opus`、`wav` 或 `ape` 时会提示不可播放，并尝试更低音质。
- 在线歌单和排行榜一次最多读取 500 首。
- 移动歌单歌曲、收藏专辑和关注艺人需要支持条件更新的新版云鹿音乐服务端；数据被其他客户端同时修改时需要重试。
- 评论只读，不支持点赞或发表评论。
- 没有填写云鹿音乐账号时不会提交播放历史和后台缓存；缓存是否写入由云鹿音乐的用户设置决定。
- 音源、播放缓存、音源切换和音质降级读取云鹿音乐播放器的同一套设置；MyGo 的音质设置决定首次请求的音质。
- 不支持播客、电台和云鹿音乐的管理后台功能。
- 服务器上的自定义音源必须支持所选平台；否则可以浏览，但播放会失败。
- 排行榜封面由云鹿音乐 API 提供。旧版服务端只返回榜单名称时，插件会使用随插件打包的云鹿音乐图标兜底。

## 安全

- 插件声明 `network: ["*"]`，因为服务器地址由使用者填写。
- 账号密码保存在 MyGo 的插件设置中；会话 Cookie 保存在插件自己的数据目录中。
- 通过公网使用时建议给云鹿音乐配置 HTTPS。

## 开发

```powershell
bun test
```

对真实服务器做只读检查：

```powershell
$env:YUN_MUSIC_SERVER = "http://127.0.0.1:9527"
$env:YUN_MUSIC_USERNAME = "your-user"
$env:YUN_MUSIC_PASSWORD = "your-password"
$env:YUN_MUSIC_SOURCE = "wy"
bun run test/live.js
```

服务器启用播放器密码时再加 `$env:YUN_MUSIC_PLAYER_PASSWORD`。加上 `$env:YUN_MUSIC_WRITE = "1"` 会额外验证收藏、歌单增删和播放历史；请使用测试账号。
